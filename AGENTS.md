# Hemavathi Saidhu — Portfolio & Admin Portal

This repository contains the source code for Hemavathi Saidhu's developer portfolio, interactive AI resume tailor, and dynamic administrative dashboard.

## Tech Stack
- **Framework**: TanStack Start / React 19 / Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS / Vanilla CSS
- **Media**: Cloudinary
- **State**: React Context with LocalStorage persistence
